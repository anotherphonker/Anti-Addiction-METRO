## 🇹🇷 | Türkçe Dokümantasyon

### 🎯 Projenin Felsefesi ve Amacı
**Metro UI Anti-Bağımlılık Yazılımı**, bireylerin sigara, elektronik sigara (vape), kumar & bahis, fap & porno, alkol, aşırı ekran & sosyal medya tüketimi, şeker/abur cubur veya kendisinin belirlediği herhangi bir zararlı alışkanlıktan kurtulmasını desteklemek amacıyla tasarlanmış **evrensel bir irade ve disiplin takip sistemidir**. 

Yapay zorlamalardan kaçınarak kullanıcının dikkatinin faydalı aktivitelere yönlendirilmesini sağlar. Hiçbir sunucuya bağlanmayan yapısı sayesinde veri mahremiyetini en üst düzeye çıkarır.

### ✨ Öne Çıkan Özellikler

* 🚀 **Tek Dosya Mimarisi (Zero Dependency):** Kurulum yok, sunucu yok, veri tabanı yok! Yalnızca `index.html` dosyasını tarayıcınızda açmanız yeterlidir. İster bilgisayarınızda bir çevrimdışı uygulama olarak açın, ister Github Pages gibi ücretsiz bir servise yükleyin.
* 🌀 **Orijinal Windows 8 Metro UI Deneyimi:** Açılışta Windows 8'in klasik **5 noktalı yörünge animasyonu** ve 3D perspektifle eğimli özel **Özgürlük Kalkanı Logosu** yer alır. Arka plan animasyonları ve kiremit (tile) yerleşimleriyle harika bir nostaljik bütünlük sunar.
* 🧊 **3D Tuğla Eğilme Efekti (3D Tilt):** Metro bloklarının (Tile) sağ, sol veya köşelerine tıkladığınızda Windows 8'deki karakteristik 3D esneme ve gömülme hissi yaratılır.
* 📱 **Cross-Platform (Tam Akıllı Optimizasyon):** CSS Grid'in gelişmiş `minmax(0, 1fr)` algoritması sayesinde 1080x2400 dik mobil telefon ekranlarından 1366x768 bilgisayarlara ve dev ekranlara kadar hiçbir şekilde taşma, metin kırpma veya sağa kayma barı çıkarmaz.
* 🔒 **%100 Çevrimdışı ve Gizli (Privacy First):** Girdiğiniz hiçbir ad, hedef, not veya görev internete veya sunuculara iletilmez. Her şey tarayıcınızın yerel hafızasında (`localStorage`) çevrimdışı ve güvenle saklanır.
* 💾 **Yedekleme ve Geri Yükleme (Export / Import):** İradenize dair serinizi, notlarınızı ve rekorunuzu tek tıkla küçük bir `.json` dosyası olarak indirebilir, farklı bir cihaza veya tarayıcıya anında yükleyebilirsiniz (Akıllı hata denetimi içerir).
* 🌍 **Gerçek Çift Dil Desteği (TR / EN):** Ekranın sağ üst köşesindeki bayrak butonuna (🇹🇷 / 🇬🇧) basıldığı anda, sayfa bile yenilenmeden açılış ekrandan ayarlara, uyarılardan tarih/saat formatına kadar tüm sistem ilgili dile döner.

### 🛠️ Entegre Mini Uygulamacıklar
1. **📊 İlerleme ve Rozet Paneli:** Günler, toplam saatler, haftalar, deneme sayıları ve kişisel rekorunuz. 90 günlük arınma hedefine göre adım adım kilit açan 4 ana kazancın (1 Gün, 1 Hafta, 1 Ay, 90 Gün) animasyonlu paneli ve 9 aşamalı rütbe/seviye takibi!
2. **✔️ Canlı Önizlemeli Yapılacaklar Listesi (To-Do Live Tile):** Boş vakitlerinizi dolduracak görevler veya hedefler ekleyebilirsiniz. Tamamladıklarınızın üzerini çizip silebilirsiniz. Bekleyen ilk görev ve sayaç doğrudan ana karoda (Live Tile) gösterilir.
3. **📝 İrade Günlüğü & Notlar:** İradenizin zorlandığı zamanlarda hislerinizi ve kendinizi sakinleştirme stratejilerinizi kaydedebileceğiniz gün ve saat damgalı dahili not uygulamacığı.
4. **🧮 Metro Hesap Makinesi:** Temiz, hızlı ve şık bir arayüze sahip işlevsel pencere tabanlı matematiksel hesap makinesi.
5. **💡 Günlük Motivasyon Alıntıları:** Üzerine her tıkladığınızda filozoflardan ve sporculardan (Platon, Victor Hugo, Warren Buffett vb.) özenle seçilmiş irade sözlerini yenileyen motivasyon blokları.

### 🚀 Nasıl Kullanılır?
1. Bu deposu bilgisayarınıza veya telefonunuza indirin / klonlayın:
   ```bash
   git clone https://github.com/anotherphonker/Anti-Addiction-METRO.git
   ```
2. İndirdiğiniz klasördeki `index.html` dosyasını favori tarayıcınızla (Chrome, Safari, Firefox, Edge vb.) çift tıklayarak açın.
3. Açılan kurulum ekranda (OOBE); hitap adınızı yazın, bırakmayı hedeflediğiniz alışkanlığı listeden (veya kendim yazacağım kısmından) seçin ve seriye başladığınız günü girin.
4. Sistemin ve iradenizin tadını çıkarın!

### 📱 Android Telefonlarda Açma
Bazı Android dosya yöneticileri `.html` dosyalarını Firefox gibi tarayıcılarda doğrudan açamayabilir. Böyle bir sorun yaşarsanız şu yöntemi kullanabilirsiniz:

1. Google Play Store üzerinden **File Manager Plus** adlı dosya yöneticisini indirin.
2. GitHub deposunu telefonunuza ZIP olarak indirin.
3. İndirdiğiniz ZIP dosyasını klasöre çıkarın.
4. **File Manager Plus** uygulamasında proje klasörünü açın.
5. `index.html` dosyasına dokunun ve kullanmak istediğiniz tarayıcıyı seçin.

> Not: Uygulamanın ilerleme, görev ve not verileri seçtiğiniz tarayıcının `localStorage` alanında saklanır. Verilerinizi kaybetmemek veya başka bir tarayıcıya taşımak için Ayarlar bölümündeki **Dışa Aktar / İçe Aktar** özelliğini kullanın.

## 🇬🇧 | English Documentation

### 🎯 Philosophy & Purpose
The **Metro UI Anti-Addiction & Willpower Tracker** is a universal self-discipline application built to help individuals break free from addictive behaviors—including smoking, vaping, gambling & betting, fap & porn, alcohol, excessive screen/social media usage, sugar/junk food, or any custom harmful habit.

Instead of rigid force, it nudges the user to divert their focus and time toward productive activities. Built with a decentralized architecture, it ensures complete user privacy.

### ✨ Highlights & Core Features

* 🚀 **Zero-Dependency Single HTML Architecture:** No frameworks to assemble, no servers to configure, no databases to spin up! Simply double-click and launch `index.html` directly inside any web browser offline, or deploy instantly to free static hosting like GitHub Pages.
* 🌀 **Authentic Windows 8 Metro UI Experience:** Includes an homage to the classic Windows 8 **orbital 5-dot ring bootloader**, paired with an original 3D angled **Freedom Shield emblem** that seamlessly transitions into the high-contrast tile interface.
* 🧊 **Interactive 3D Tile Tilt:** Tapping or clicking any tile corner recreates the iconic Windows 8 physical depression and deep 3D surface tilt feedback.
* 📱 **Cross-Platform & Responsive Grid Optimization:** Utilizing CSS Grid's intelligent `minmax(0, 1fr)` architecture, the application scales effortlessly across all screens—from modern 1080x2400 vertically oriented smartphones to laptops and large monitors—with zero horizontal scrolling or broken layouts.
* 🔒 **100% Offline & Privacy-First:** Nothing is tracked, monetized, or beamed to a cloud server. Every name, habit, log, task, and date you submit is encrypted natively inside your browser's offline local storage (`localStorage`).
* 💾 **Seamless Backup & Recovery (Export / Import):** Export your complete progress history into a portable `.json` backup file with a single click, and safely migrate or restore your data across devices instantly (built with file validity checks).
* 🌍 **Bilingual Interface (EN / TR):** Featuring real-time locale shifting via the top-right flag selector (🇹🇷 / 🇬🇧). From OOBE setup wizards and system dialogs to date/time formatters and motivational quotes, everything updates seamlessly without refreshing the page.

### 🛠️ Built-in Metro Mini-Apps
1. **📊 Progress Analytics & Badge Board:** Live metrics tracking continuous days clean, total hours elapsed, weeks, attempts count, and your personal best streak. Accompanied by a 90-day progress circle, 4 milestone achievement badges (1 Day, 1 Week, 1 Month, 90 Days), and a 9-stage leveling hierarchy!
2. **✔️ To-Do List with Live Tile Preview:** Keep your mind and calendar occupied by creating actionable tasks or productive goals. Your total pending tasks count and your highest-priority objective are directly streamed onto the front Metro dashboard!
3. **📝 Willpower Journal & Notes:** A time-stamped notebook applet where you can log personal coping mechanisms, emotional checkpoints, and strategies when facing urges.
4. **🧮 Metro UI Calculator:** A clean, accurate, and rapid window-based mathematical calculator styled natively in the Windows Metro design language.
5. **💡 Daily Motivational Quotes Engine:** Tap on the indigo tile to trigger random inspirational quotes curated from stoics, thinkers, and athletes (Plato, Victor Hugo, Warren Buffett, Lance Armstrong, David Goggins, etc.).

### 🚀 Getting Started
1. Clone or download this repository onto your desktop, laptop, or mobile device:
   ```bash
   git clone https://github.com/anotherphonker/Anti-Addiction-METRO.git
   ```
2. Locate the folder and open `index.html` inside your favorite web browser (Chrome, Edge, Safari, Firefox, Opera, etc.).
3. Complete the brief initial OOBE setup: choose how you want to be greeted, select the addiction/habit you wish to conquer, and set the day your streak commenced.
4. Stay disciplined and embrace freedom!

### 📱 Opening the App on Android Phones
Some Android file managers may not allow local `.html` files to open directly in browsers such as Firefox. If you encounter this issue, use the following method:

1. Download **File Manager Plus** from the Google Play Store.
2. Download the GitHub repository to your phone as a ZIP file.
3. Extract the downloaded ZIP file into a folder.
4. Open the project folder with **File Manager Plus**.
5. Tap `index.html` and select the browser you want to use.

> Note: Progress, task, and journal data is stored in the selected browser's `localStorage`. Use the **Export / Import** feature in Settings to avoid data loss or move your data to another browser.
